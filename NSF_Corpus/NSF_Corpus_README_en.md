The Corpus consists of text files (.txt) containing the transcriptions of the historical documents used in the project.

The **Corpus_GT** contains the ‘Ground Truth’ versions of the documents.
These are the verbatim transcriptions produced by specialists in New Spain palaeography, in accordance with the project’s Transcription Criteria.

The various **Corpus_HTR** files contain the automatic transcriptions generated by our handwritten text recognition (HTR) models hosted on [Transkribus](https://app.transkribus.eu).
The name of each corpus indicates the HTR model that generated the transcriptions. For example, the transcriptions included in “Corpus_Encadenada_m2t4” were produced by the HTR model for the ‘Procesal encadenada’ script, version m2t4.

Most GT and HTR files exist in pairs (for example, BnF_110_02_GT -- BnF_110_02_Procesal_m3t4_HTR), as the accuracy of an HTR transcription is assessed by comparing it with its GT.
However, there may be one or more HTR files for a single GT file, should several transcriptions of the same page have been generated using different HTR models.

### File names
The names of the .txt files follow this naming convention:  
**{Archive/Institution} _ {Fund/Collection} _ {volume/box} _ {file/reference number} _ {page} _ {transcription type}**  
For example:
- AGI_CONTRATACION_5500_N2_R15_01_GT
  - refers to: Archivo General de Indias, Contratación fund, reference number 5500_N2_R15, page 01, Ground Truth transcription
- AGN_HospJesus_c380_exp005_04_Redonda_m1t3_HTR
  - refers to: Archivo General de la Nación (Mexico), Hospital de Jesús Fund, box 380, file 5, page 04, HTR transcription produced using the Redonda m1t3 model

## Corpus Versions
### Corpus_oct2025
This was the first version of the Corpus. It includes the historical documents used to train the HTR models for the *Italica cursiva*, *Procesal simple*, *Procesal encadenada* and *Redonda* scripts. It includes the GT and HTR versions obtained using their respective models.
- Corpus_GT
  - 88 documents/folders, 568 pages/.txt files
- Corpus_HTR_Encadenada_m2t4
  - 6 documents/folders, a single .txt file per document (not divided into individual pages).
- Corpus_HTR_Italica_cursiva_m3t1
  - 47 documents/folders, 335 pages/txt files
- Corpus_HTR_Procesal_m3t4
  - 24 documents/folders, 146 pages/.txt files
  - Note: This is not the latest version of the model for Procesal simple. The latest version is m3t7 (see below).
- Corpus_HTR_Redonda_m1t3
  - 12 documents/folders, 80 pages/.txt files


### Corpus_feb2026
This version of the Corpus includes the historical documents used for the training **and evaluation** of the HTR models for the *Italica cursiva*, *Procesal simple*, *Procesal encadenada* and *Redonda* scripts. It includes the GT and HTR versions obtained using their respective models.
- Corpus_GT
  - 157 documents/folders, 2,409 pages/.txt files
- Corpus_HTR_Chained_m2t4
  - 15 documents/folders, 716 pages/.txt files
- Corpus_HTR_Italic_Cursive_m3t1
  - 54 documents/folders, 498 pages/.txt files
- Corpus_HTR_Procesal_m3t7
  - 85 documents/folders, 1,102 pages/.txt files
- Corpus_HTR_Redonda_m1t3
  - 19 documents/folders, 97 pages/.txt files

>[!CAUTION]
>When analysing this version of the Corpus using the NAOMI process, we identified misalignment issues in 158 pairs of GT-HTR files, where one of the two .txt files has more lines than the other.
>These affected 76 *italica cursiva*, 35 *encadenada*, 46 *procesal* and 1 *redonda* pairs. Upon reviewing each pair of files, the main problems identified were:
>- Extra lines in the GT files.
>The source of this problem lies in the process of exporting .txt files in Transkribus: when a transcription is exported from a document’s version history, the text of the latest version in the history is appended to the text of that version.
>Therefore, if the GT was not the latest version – as is the case with many of our transcriptions where the GT was produced first and then one or more HTRs were run – then, when that GT is exported, the .txt file also includes the text of the latest HTR in the history.
Each of the files was reviewed and corrected so that their lines matched.
>- AGI_CONTRATACION_1170A_N10.
>This document contained almost 100 GT-HTR pairs with alignment errors in the text lines, affecting *encadenada*, *cursiva* and *procesal*. The problem arose because the HTRs were run against near-final versions of the human transcriptions that had not yet been fully proofread, meaning they often did not correspond to the final GT.
To correct the affected files, the HTRs for this document were run again, this time using the final version of the GT.
>- Lines present in the GT but absent from the HTR.
>This was an unusual case, exclusive to the first documents we worked on for the *Italica cursiva* model and almost always found in BnF documents.
Some lines had a baseline but no polygon. This meant that the line did contain text in the GT (as it had been added manually), but not in the HTR as there was no polygon or input image for the model.
To correct this, new baselines and polygons were added to the affected lines.
>- UIA_Ms149_Exp2.
>On several pages of this document, the GT was not completely clean. Empty lines had been left in the margins but had not been removed, so they were included in the HTR, where they appeared with text.
To correct this, text was added to the GTs where necessary.
